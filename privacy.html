Politique de Confidentialité

Dernière mise à jour : Janvier 2025 · TAF Finance v2.0

🛡️ Vos données vous appartiennent à 100%

📌 1. Résumé rapide

TAF est une application de gestion financière personnelle qui fonctionne entièrement dans votre navigateur, sans serveur, sans compte, sans connexion internet requise.

  • Toutes vos données sont stockées localement sur votre appareil.
  • Aucune donnée n'est envoyée vers un serveur externe.
  • Aucune inscription ni mot de passe n'est requis.
  • Vous pouvez supprimer toutes vos données à tout moment.

💾 2. Stockage des données (localStorage)

TAF utilise exclusivement le mécanisme localStorage de votre navigateur pour conserver vos informations entre les sessions.

Les données stockées comprennent :

  • Vos dépenses (montant, catégorie, date, description)
  • Vos objectifs d'épargne (nom, montant cible, progression)
  • Vos paramètres (devise, langue, thème, nom d'utilisateur)
  • Votre photo de profil (si fournie, encodée localement)
  • Votre budget mensuel et vos revenus saisis

💡 localStorage est une zone de stockage propre à votre navigateur, sur votre appareil. Elle ne peut être lue que par TAF, uniquement sur ce navigateur.

🚫 3. Ce que nous ne faisons pas

  • Nous ne collectons aucune donnée personnelle ou financière.
  • Nous n'utilisons aucun tracker, aucun cookie de suivi.
  • Nous ne vendons aucune information à des tiers.
  • Nous n'envoyons aucune donnée vers un serveur distant.
  • Nous n'utilisons aucune API externe liée à vos finances.
  • Il n'y a aucune publicité dans l'application.

🔒 4. Sécurité de vos données

Vos données sont protégées par les mécanismes natifs de votre navigateur :

  • Le Same-Origin Policy empêche tout autre site d'accéder à vos données TAF.
  • Les données sont isolées par domaine dans le localStorage.
  • Personne, pas même nous, ne peut accéder à vos données à distance.

⚠️ Attention : si vous effacez le cache / les données de votre navigateur, ou utilisez un mode de navigation privée, vos données TAF seront supprimées. Pensez à exporter régulièrement en CSV depuis les paramètres.

✋ 5. Vos droits & contrôle

Vous avez le contrôle total sur vos données :

  • Accès : toutes vos données sont visibles dans l'application.
  • Export : exportez l'intégralité en fichier CSV (Paramètres → Exporter).
  • Suppression : réinitialisez tout depuis Paramètres → Zone de danger.
  • Portabilité : le format CSV exporté est universel.

🌐 6. Connexion internet

TAF peut fonctionner hors ligne une fois chargé. La connexion internet est uniquement nécessaire au premier chargement des polices de caractères (Google Fonts). Aucune de vos données n'est transmise lors de ce chargement.

Pour une utilisation 100% hors ligne, vous pouvez télécharger et héberger TAF localement sur votre appareil.

📧 7. Contact

TAF est un projet indépendant à but non lucratif. Pour toute question relative à la confidentialité ou au fonctionnement de l'application, vous pouvez consulter la documentation du projet.

Cette politique de confidentialité peut être mise à jour pour refléter des améliorations de l'application, sans jamais modifier notre engagement : vos données vous appartiennent, elles restent sur votre appareil.
